# Body Pairs — Memory Game

A two-player picture memory game for Go Getter 1, Unit 4. Match singular and plural body parts.

**by Milena Vasileva · [ChattyBunny on VK](https://vk.ru/club225157002)**

## Play

[Open the live game](https://body-pairs-milena.vasileva-mila123.chatgpt.site/)

- Choose 6, 8, all 13 pairs, or a custom set.
- Enter both player names. A correct pair earns one point and an extra turn.
- A wrong pair closes after 3 seconds and passes the turn.
- Enable **Take your time** to close a wrong pair manually.
- Optional word labels, card sounds and a victory tune.
- Both players share one screen; moves do not sync across devices.

## Run locally

Open `index.html` in a modern browser. No installation or build step is needed. Fonts use Google Fonts, with system fallbacks.

## GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, then **main / (root)** and Save.

Use your GitHub Pages URL in an iframe or paste the live game URL into Holst’s iframe tool. The in-game **Embed** button currently provides the original live hosting URL.

## Files

`index.html`, `style.css`, `app.js`, and the `.webp` picture files are the complete static game. `pairs.json` lists the vocabulary pairs.
